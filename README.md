# Jornada Empreendedora — Direito Empresarial

Protótipo de jogo educacional para estudar etapas da abertura de uma empresa no Paraná.

## Como jogar
Abra `index.html` no navegador ou acesse o site publicado no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie o arquivo `index.html` e o `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
6. Aguarde a publicação; o endereço aparecerá nessa mesma página.

## Arquivos
- `index.html`: jogo completo (HTML, CSS e JavaScript integrados).
- `README.md`: instruções do projeto.

Não é necessário instalar dependências nem configurar um servidor. A fonte Nunito é carregada do Google Fonts quando há conexão; sem conexão, o jogo usa fontes alternativas do sistema.

## Observação
O conteúdo é uma simulação acadêmica. As exigências de abertura, enquadramento, licenciamento e funcionamento dependem da atividade e das normas aplicáveis. Nenhum CNPJ ou certificado real é emitido.
